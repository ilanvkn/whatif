# Contributing

Use Node 22+; no install step is required for the core. Run `npm test`, `npm run check` and `npm run demo`.

Changes must preserve the distinction between requested scenarios, measured observations and projections. Include a relevant failure/boundary test for runtime changes. Never claim an optional engine was executed merely because a repository was cloned or an executable was discovered.

For adapters include source/version/license, data destinations, execution scope, resource limits, cancellation semantics, artifact format and actual integration evidence. Use synthetic fixtures by default; no live third-party traffic in CI. Do not commit case outputs containing private application data.

Original contributions are under the repository's MIT license. Do not copy third-party code without preserving its applicable license and notices.
